# Tailwind Color Configuration

## Color Choices

- **Primary:** `blue` — Used for buttons, links, key accents, active states
- **Secondary:** `amber` — Used for tags, highlights, bitcoin-related elements, notification badges
- **Neutral:** `slate` — Used for backgrounds, text, borders, cards

## Usage Examples

Primary button: `bg-blue-600 hover:bg-blue-700 text-white`
Secondary badge: `bg-amber-100 text-amber-800` or `bg-amber-500/10 text-amber-500`
Neutral text: `text-slate-600 dark:text-slate-400`
Card background: `bg-slate-800 dark:bg-slate-900`
Bitcoin orange accent: `#f7931a` (notification badge)

## Dark Theme

bitCaster defaults to dark theme. Key dark-mode patterns:
- Page background: `bg-slate-950`
- Card background: `bg-slate-900` or `bg-slate-800`
- Text primary: `text-white`
- Text secondary: `text-slate-400`
- Borders: `border-slate-700`
